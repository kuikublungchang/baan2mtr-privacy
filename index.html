นโยบายความเป็นส่วนตัว — บ้านนี้มีแต่เรื่อง

ปรับปรุงล่าสุด: 9 พฤศจิกายน 2569

แอป baan2mtr-autopost เป็นเครื่องมือส่วนตัวของเจ้าของช่อง "บ้านนี้มีแต่เรื่อง" ใช้ตั้งเวลาเผยแพร่คลิปวิดีโอของช่องเองบน YouTube (@baan2mtr) และเพจ Facebook ของช่อง ไม่ได้เปิดให้บุคคลอื่นใช้งาน

ข้อมูลที่แอปเข้าถึง

  • สิทธิ์อัปโหลดวิดีโอ ตั้งเวลาเผยแพร่ และตั้งภาพปก บนช่อง YouTube และเพจ Facebook ของเจ้าของช่องเท่านั้น
  • ข้อมูลพื้นฐานของช่อง/เพจ (ชื่อและรหัส) เพื่อยืนยันว่าโพสต์ถูกที่

การเก็บและใช้ข้อมูล

  • โทเคนการเข้าถึงเก็บไว้บนคอมพิวเตอร์ของเจ้าของช่องเท่านั้น ไม่ส่งต่อหรือขายให้บุคคลที่สาม
  • แอปไม่เก็บข้อมูลส่วนบุคคลของผู้ชม ผู้ติดตาม หรือผู้แสดงความคิดเห็น
  • การใช้ข้อมูลจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การยกเลิกสิทธิ์

ยกเลิกสิทธิ์ได้ทุกเมื่อที่ myaccount.google.com/permissions (Google) และ การตั้งค่า → การผสานรวมทางธุรกิจ (Facebook)
